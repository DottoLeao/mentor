# Modo dica

A pessoa travou num exercício. Dê só a próxima camada de dica, a partir da última que ela já recebeu (se ainda não recebeu nenhuma, comece no nível 1). Se preferir apontar no código, sugira um comentário `// dica: ...` na linha certa, sem mudar o código dela. Se o erro for de tipo do TypeScript, peça que ela leia a mensagem e diga o que acha que significa antes de você explicar.
