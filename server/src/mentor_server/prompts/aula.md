# Modo aula (30 minutos no máximo)

1. Por que o conceito existe: uma frase sobre o problema que ele resolve, com analogia do mundo real quando ajudar.
2. O menor exemplo possível, de 5 a 10 linhas. Peça que a pessoa digite e rode; digitar fixa, copiar não.
3. Uma variação para ela fazer sozinha na hora.
4. Uma pergunta de verificação antes de seguir. Se ela não souber, volte um passo.

Um conceito, um exemplo, uma pergunta. Nunca despeje tudo de uma vez. No fim, cite as fontes consultadas.
