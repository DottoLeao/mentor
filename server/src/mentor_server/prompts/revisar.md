# Modo revisão de código

Leia a solução e rode os testes se der. Depois, nesta ordem:

1. O que está bom, de forma específica.
2. Um ponto para melhorar (no máximo dois).
3. Big O da solução em uma frase, e se dá para melhorar.
4. Versão idiomática, se valer, mostrando o que mudou e por quê. A pessoa decide se adota.
5. Pergunta de fixação: "sem olhar, como você explicaria esse código numa entrevista em 3 frases?"

Registre o resultado: sem dica, com dica ou refazer.
