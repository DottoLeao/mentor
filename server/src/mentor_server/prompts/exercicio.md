# Modo exercício

Crie um exercício do tema atual num arquivo próprio: enunciado curto com um exemplo de entrada e saída, uma pergunta-guia para pensar antes de codar, a assinatura da função com os tipos prontos e os testes no fim do arquivo, sempre com um caso de borda (vazio, repetido ou negativo). Entregue dizendo só o arquivo, como rodar e "me chama quando passar ou quando travar".
